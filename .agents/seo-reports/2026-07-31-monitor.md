## Out of Scope — Needs Human

The following could not be verified from this sandbox (site unreachable):

1. **Live sitemap validation** — `/sitemap.xml` returns 403 from sandbox. Needs verification that all ~700+ URLs return HTTP 200, lastmod values are reasonable, and no stale/dead URLs are included.

2. **Canonical header confirmation** — cannot verify that the `<link rel="canonical">` renders correctly in the server-rendered HTML for dynamic routes (`/city/[city]`, `/algorand/[slug]`, `/market/[date]`).

3. **JSON-LD parse validation** — JSON-LD blocks are constructed from template literals and runtime data. Live render needed to confirm valid JSON output (no unterminated strings, no encoding issues).

4. **Image dimension attributes** — `<Image>` component usage in property cards and the analyzer page should specify `width`/`height` to prevent layout shift. Not auditable without live DOM.

5. **Font `font-display: swap`** — DM Serif Display and DM Mono are loaded via `next/font`. The font config in `app/layout.tsx` should be verified to set `display: "swap"`. If missing, fonts block rendering. Not detectable from static analysis.

6. **Analyzer page OG image** — the `/analyzer` page has no metadata at all (P0 finding above). When this is fixed, it also needs an OG image route (`/analyzer/opengraph-image`) or a shared fallback.

7. **`/contact` and `/privacy` OG/Twitter** — low-priority pages but they share previews on social when linked. A single boilerplate OG block would resolve this without measurable effort. Left to human judgment.
