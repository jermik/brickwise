## Finding 1 (HIGH): Probable title template doubling — 15+ pages

### Root cause

`app/layout.tsx` declares:
```ts
title: { template: "%s | Brickwise" }
```

Pages that set `metadata.title` as a **plain string** (not `{ absolute: ... }`) have their string substituted into `%s`. If that string already ends in `| Brickwise`, the rendered `<title>` becomes:

> `"… | Brickwise | Brickwise"`

This is standard Next.js App Router behavior. The pattern `{ absolute: "…" }` bypasses the template; a plain string does not.
